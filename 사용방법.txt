병준이의 숙제 노트 — 사용방법

1. 실행하기
설치나 코딩 없이 아래 주소를 휴대폰 또는 컴퓨터 브라우저로 엽니다.
https://byungjun-homework-notebook.basicstone14.chatgpt.site
사이트에 초대받은 본인의 ChatGPT 계정으로 로그인하세요.
엄마와 병준이는 각자 계정으로 동일한 숙제와 시간표를 확인할 수 있습니다.
로그인 정보를 다른 사람에게 전달하지 마세요. 별도 계정 초대가 필요한 경우 페이지 제작 대화에서 요청할 수 있습니다.
즐겨찾기 또는 브라우저 메뉴의 ‘홈 화면에 추가’를 사용하면 다음에 쉽게 열 수 있습니다.

2. 숙제 등록하기
‘숙제 추가’ 또는 시간표에 있는 ＋ 버튼을 누릅니다.
과목, 마감일, 제목, 내용을 입력하고 ‘숙제 저장’을 누릅니다.
마감일은 해당 과목의 다음 수업일을 제안하며 자유롭게 바꿀 수 있습니다.
‘숙제를 공유 저장소에 저장했어요’라는 안내가 나오면 저장된 것입니다.
교재명, 페이지, 선생님 전달 사항, 준비물 등을 내용에 적을 수 있습니다.
숙제는 수업 후 학생 또는 엄마가 직접 입력합니다. 학원에서 자동 수집하는 기능은 없습니다.

3. 학생이 완료 표시하기
병준이는 설정된 학생 계정으로 로그인합니다.
숙제를 끝내면 ‘숙제 다 했어요’를 누릅니다.
이 숙제는 ‘엄마 확인 대기’로 바뀝니다.
다시 누르면 학생 완료를 취소하며, 엄마 확인도 함께 취소됩니다.

4. 엄마가 최종 확인하기
엄마는 설정된 엄마 계정으로 로그인합니다.
‘확인 대기’ 필터를 누르고 숙제 내용을 살펴봅니다.
‘엄마 확인 완료’를 누르면 최종 완료 상태가 됩니다.
학생이 먼저 완료한 숙제만 엄마가 확인할 수 있습니다.
확인을 다시 누르면 엄마 확인이 취소됩니다.
권한은 실제 로그인 계정으로 정해집니다. 엄마 계정만 수정·삭제·시간표 변경·엄마 확인을 할 수 있습니다.
병준이는 숙제·사진 등록, 학생 완료·예습 통과 체크와 예습시험을 사용할 수 있습니다.
다른 초대 계정은 보기만 가능하며, 엄마로 화면을 전환해 권한을 얻을 수 없습니다.

5. 숙제 수정·삭제하기
엄마 계정으로 로그인해 각 숙제의 ‘수정’을 눌러 내용을 바꾸고 저장합니다.
수정하면 학생 완료와 엄마 확인이 모두 초기화됩니다. 바뀐 내용을 다시 확인해 주세요.
‘삭제’를 누르면 확인 창이 나옵니다. 삭제한 숙제는 복구할 수 없습니다.
다른 기기에서 먼저 수정한 경우 덮어쓰지 않고 안내합니다. 창을 닫고 최신 숙제를 다시 열어 수정하세요.

6. 시간표 바꾸기
엄마 계정으로 로그인해 시간표 옆 ‘수정’을 누릅니다.
요일, 과목, 시작 시간과 종료 시간을 화면에서 바꿀 수 있습니다.
‘수업 추가’로 새 수업을 추가하고, × 버튼으로 수업을 삭제합니다.
월~일 모두 등록할 수 있습니다. 오후 2시는 14:00, 오후 7시는 19:00입니다.
‘시간표 저장’을 눌러 마무리합니다.
시간표를 바꿔도 기존 숙제 기록은 삭제되지 않습니다.
모든 날짜와 ‘오늘’ 표시는 한국 시간(Asia/Seoul) 기준입니다.

7. 공유 저장과 동기화
숙제와 시간표는 서버의 공유 데이터베이스에 저장됩니다.
페이지가 열려 있으면 약 10초마다 다른 기기의 변경 사항을 불러옵니다.
다른 앱을 쓰다가 페이지로 돌아와도 새로 불러옵니다.
인터넷 연결이 있어야 저장할 수 있습니다. 오류가 나면 입력 창을 닫지 말고 연결 후 다시 저장해 주세요.
‘다시 연결’을 누르면 최신 기록을 불러옵니다.
브라우저 데이터를 지우거나 기기를 바꿔도 서버에 저장한 기록은 남아 있습니다.
숙제는 주가 바뀌거나 마감일이 지나도 자동 삭제되지 않습니다.

8. 기록 내려받기
컴퓨터 화면 왼쪽의 ‘기록 내려받기’ 또는 사용 안내 아래 같은 버튼을 누릅니다.
전체 숙제와 시간표가 JSON 파일로 내려받아집니다.
이 파일은 기록 보관용이며 화면에서 다시 가져오는 기능은 없습니다.
기록에는 숙제 내용이 들어 있으므로 개인적으로 보관하세요.

계정을 바꾸려면 오른쪽 위 ‘계정 변경’을 눌러 다시 로그인하세요.

9. 화면을 더 바꾸고 싶을 때
이 페이지를 만든 대화에서 ‘색을 바꿔줘’, ‘과목을 추가해줘’처럼 요청하세요.
일상적인 숙제·시간표 변경은 페이지에서 바로 할 수 있어 개발 도구가 필요하지 않습니다.

10. 수·금 영어 단어 사진 올리기
‘단어 사진 올리기’를 누르고 시험 날짜(수·금)와 사진 이름을 정합니다.
‘사진 선택’으로 사진을 고르거나 휴대폰의 ‘사진 찍기’로 촬영합니다.
미리보기를 확인하고 ‘사진 저장’을 누르면 사진만 공유 저장됩니다.
사진의 글자를 자동 인식하거나 단어·뜻을 입력하는 단계는 없습니다.
원본 25MB 이하 사진 한 장을 선택할 수 있고, 저장용으로 자동 축소합니다.
JPG·PNG·WEBP를 권장합니다. HEIC를 열지 못하면 JPG로 바꿔 다시 선택하세요.

11. 사진으로 예습하고 통과 체크하기
‘사진 보고 예습하기’를 눌러 사진을 크게 보며 공부하거나 종이에 시험을 봅니다.
예습을 마치면 사진 아래 또는 시험 목록의 ‘예습 통과’를 직접 체크합니다.
엄마와 병준이 모두 체크할 수 있고, 약 10초 안에 다른 기기에도 반영됩니다.
다시 체크하면 통과 표시를 취소할 수 있습니다.
사진 방식에서는 자동 채점이나 점수 계산을 하지 않습니다.
사진·이름·날짜를 수정해 저장하면 통과 체크가 초기화됩니다.
이미 저장했던 단어 목록과 자동 채점 시험 기록은 그대로 확인할 수 있습니다.
기존 시험을 수정해 사진 방식으로 저장하면 이전 단어 목록·점수·통과 표시가 초기화됩니다.
숙제의 학생 완료·엄마 확인과 사진 예습 통과는 별도로 관리합니다.
기록 내려받기 JSON에는 사진 파일이 포함되지 않습니다.

12. 마감 임박 숙제 먼저 확인하기
페이지 첫 화면 위쪽에 ‘마감 임박 숙제’가 표시됩니다.
마감이 지났거나 오늘·내일까지 해야 하는 숙제를 모아 보여줍니다.
빨간색: 마감 지남 / 주황색: 오늘 마감 / 노란색: 내일 마감입니다.
날짜와 ‘오늘·내일’은 한국 시간(Asia/Seoul) 기준입니다.
숙제를 누르면 선택해 둔 과목·상태 필터를 풀고 해당 숙제로 바로 이동합니다.
임박한 숙제가 4개보다 많으면 ‘모두 보기’로 전체 목록을 펼칠 수 있습니다.
학생 완료 숙제는 급한 할 일에서 빠지고, 엄마 확인 대기로 구분됩니다.
‘확인 대기 보기’를 누르면 전체 엄마 확인 대기 목록으로 이동합니다.
엄마 확인까지 끝난 숙제는 마감 임박 영역에서 제외됩니다.
임박한 숙제가 없으면 없다는 안내를, 연결하지 못하면 확인할 수 없다는 안내를 표시합니다.
알림은 페이지 안에서 표시되며, 페이지가 닫혀 있을 때 별도 메시지를 보내지는 않습니다.
