요일과목시작종료

차곡차곡 사용 안내

설치 없이 주소만 열면 준비 끝.
병준이와 엄마가 함께 쓰는 작은 숙제 노트예요.

01. 다른 기기에서 열기

휴대폰이나 컴퓨터에서 같은 페이지 주소를 열고, 사이트에 초대된 본인의 ChatGPT 계정으로 로그인해 주세요. 엄마와 병준이는 각자 계정으로 같은 기록을 볼 수 있어요. 숙제 기록은 공유 저장소에 보관되며, 화면이 열려 있으면 약 10초마다 새 내용을 불러와요. 홈 화면에 추가하거나 즐겨찾기해 두면 편해요.

02. 숙제 작성하고 저장하기

위쪽 ‘숙제 추가’ 또는 시간표의 ＋를 누르세요. 과목, 마감일, 제목과 내용을 적고 ‘숙제 저장’을 눌러요. 저장 안내가 나와야 보관된 거예요. ‘수정’으로 내용을 바꾸고 ‘삭제’로 지울 수 있어요. 삭제하면 복구할 수 없어요.

03. 학생이 완료 체크하기

병준이 계정으로 로그인하면 학생 체크를 사용할 수 있어요. 숙제를 마치면 ‘숙제 다 했어요’를 눌러 주세요. ‘엄마 확인 대기’로 바뀌어요. 다시 누르면 취소되며 엄마 확인도 함께 취소돼요.

04. 엄마가 최종 확인하기

설정된 엄마 계정으로 로그인하고 ‘확인 대기’ 목록을 보세요. 숙제를 살펴본 뒤 ‘엄마 확인 완료’를 누르면 최종 완료예요. 한 번 더 누르면 확인을 취소할 수 있어요. 권한은 실제 로그인 계정에 따라 정해져요. 수정·삭제·시간표 변경·엄마 확인은 설정된 엄마 계정만 할 수 있어요. 병준이는 숙제·사진 등록, 학생 완료와 예습 통과 체크를 사용할 수 있어요. 다른 초대 계정은 보기만 가능해요.

05. 시간표 바꾸기

시간표 옆 ‘수정’을 누르면 요일·과목·시작·종료 시간을 바꿀 수 있어요. ‘수업 추가’로 토·일 수업도 넣고, ×로 수업을 지울 수 있어요. 마지막에 ‘시간표 저장’을 눌러 주세요. 코드를 고칠 필요가 없어요.

06. 저장과 기록 보관

기록은 브라우저를 닫아도 남아 있고 인터넷 연결이 필요해요. 연결이 끊기면 저장할 수 없다는 안내가 나와요. 재연결 후 다시 저장해 주세요. 동시에 같은 숙제를 수정하면 최신 기록을 확인하도록 안내해요. 마감일이 지나거나 주가 바뀌어도 숙제는 자동 삭제되지 않아요. 컴퓨터의 ‘기록 내려받기’ 또는 아래 버튼으로 JSON 백업을 받을 수 있어요.

07. 수·금 영어 단어 사진

‘단어 사진 올리기’를 눌러 시험 날짜(수·금)와 사진 이름을 정하세요. ‘사진 선택’ 또는 ‘사진 찍기’로 사진 한 장을 고른 뒤 미리보기를 확인하고 ‘사진 저장’을 누르면 돼요.

‘사진 보고 예습하기’를 눌러 사진을 크게 보며 공부하거나 종이에 시험을 보세요. 끝나면 ‘예습 통과’를 직접 체크할 수 있어요. 다시 누르면 취소되고, 엄마와 병준이의 기기에 함께 반영돼요. 사진이나 이름·날짜를 수정하면 통과 체크는 초기화돼요.

기존 단어 목록과 시험 기록은 남아 있어요. 기존 시험을 수정해 사진 방식으로 저장하면 이전 단어 목록·점수·통과 표시가 초기화돼요. 사진 파일은 ‘기록 내려받기’에 포함되지 않아요.

08. 마감 임박 숙제 먼저 보기

첫 화면 위쪽에 마감이 지났거나 오늘·내일까지 해야 하는 숙제를 모아 보여줘요. 빨간색은 마감 지남, 주황색은 오늘, 노란색은 내일 마감이에요. 날짜는 한국 시간 기준이며 화면을 다시 열거나 기록이 갱신되면 반영돼요.

숙제를 누르면 과목·상태 필터를 풀고 해당 숙제로 바로 이동해요. 4개보다 많으면 ‘모두 보기’를 누르세요. 학생이 끝낸 숙제는 급한 할 일에서 빠지고 엄마 확인 대기로 구분돼요. 엄마 확인까지 마친 숙제는 표시하지 않아요. 임박한 숙제가 없거나 연결이 안 된 경우에도 각각 안내해요.
